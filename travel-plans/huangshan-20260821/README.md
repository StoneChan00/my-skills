## 注意事项

1. **提前预约**：黄山门票需在「黄山旅游官方平台」小程序分时段预约
2. **山上酒店**：建议提前30天以上预订，旺季紧张
3. **天气**：山上温差大，即使8月也需带外套；雨天带雨衣（不打伞）
4. **轻装上山**：背包装干粮+水+换洗衣物即可，大件行李寄存汤口
5. **天都峰**：如需攀登需实名制限额预约
6. **2026暑期优惠**：6月10日-8月31日应届中高考/大学毕业生免门票
